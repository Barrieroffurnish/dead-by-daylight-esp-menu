## 🧩 About

**Dead by Daylight Menu** is a curated list of Dead by Daylight open-source tools:

- **Overlays** — on-screen helpers, layout notes, trial HUD viewer, generator tracker
- **Quality-of-Life Helpers** — perk catalog, loadout manager, overlay notes
- **Research Notes** — trial layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Trial Helpers
- Generator Tracker — practice route planning on any map
- Hook Counter Notes — review trial progress for study
- Pallet Location Map — visualize tile layouts
- Playback Notes — record and review trial runs

### 🎨 Catalog & Loadouts
- Perk Catalog — browse perks, add-ons, offerings
- Custom Loadout Notes — organize survivor and killer builds
- Aura Visibility Notes — improved readability in practice

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Camera Control Notes — manual view adjustments mid-trial
- Route Buffer Notes — chain complex maneuvers in the editor
